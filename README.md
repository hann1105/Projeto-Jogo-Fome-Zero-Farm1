# Vale Feliz - ODS 2: Fome Zero e Agricultura Sustentável

## Sobre o projeto

Vale Feliz é um jogo 2D desenvolvido no Unity com foco no tema **ODS 2: Fome Zero e Agricultura Sustentável**. A proposta do projeto é transformar esse tema em uma experiência interativa, mostrando a vivência no campo, a produção de alimentos, o cuidado com os recursos naturais e a importância dos pequenos produtores rurais.

No jogo, o jogador explora a comunidade **Vale Feliz**, um local simples, próspero para a produção agrícola e cheio de biodiversidade. A fazenda principal do projeto é a **Colheita Feliz**, um espaço que representa a realidade de muitas localidades rurais brasileiras.

## Objetivo do jogo

O principal objetivo do jogador é realizar o plantio e a colheita de diferentes culturas no espaço de cultivo da fazenda, promovendo a rotatividade ecológica e a produção de alimentos.

A ideia central é mostrar, de forma lúdica, como a pequena agricultura contribui para a alimentação, para o comércio local, para a economia das comunidades rurais e para a reflexão sobre o combate à fome.

## Relação com a ODS 2

A ODS 2 busca acabar com a fome, alcançar a segurança alimentar, melhorar a nutrição e promover a agricultura sustentável.

O projeto se conecta a esse objetivo ao destacar:

- A importância da agricultura sustentável.
- A valorização dos pequenos produtores.
- A produção local de alimentos.
- A diversidade agrícola e a rotatividade de culturas.
- O combate ao desperdício e à insegurança alimentar.
- A relação entre alimentação, cultura e economia local.

## Como executar o jogo

1. Instale o Unity Hub.
2. Instale a versão do Unity `6000.0.75f1` ou uma versão compatível da linha Unity 6.
3. Abra o Unity Hub.
4. Clique em `Add` ou `Adicionar projeto`.
5. Selecione a pasta do projeto:

   ```text
   Projeto-Jogo-Fome-Zero-Farm1
   ```

6. Aguarde o Unity importar os arquivos e carregar os pacotes necessários.
7. Abra a cena principal:

   ```text
   Assets/Scenes/SampleScene.unity
   ```

8. Clique no botão `Play` no editor Unity para iniciar o jogo.

## Controles

Use as teclas abaixo para movimentar o personagem:

- `W` ou seta para cima: mover para cima.
- `A` ou seta para a esquerda: mover para a esquerda.
- `S` ou seta para baixo: mover para baixo.
- `D` ou seta para a direita: mover para a direita.

## Como gerar uma versão executável

1. No Unity, acesse `File > Build Profiles`.
2. Escolha a plataforma desejada, como Windows.
3. Verifique se a cena `Assets/Scenes/SampleScene.unity` está incluída no build.
4. Clique em `Build`.
5. Escolha uma pasta para salvar o jogo compilado.
